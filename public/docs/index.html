Yash Khalkar Vercel API Documentation

This is the official API documentation for the Yash Khalkar portfolio on Vercel. The public API provides machine-readable profile data at /api/v1/profile. Use the OpenAPI specification to generate clients, read the authentication and rate-limit policy, or connect an AI agent through the Streamable HTTP MCP server.

REST API v1

Send a GET request to the versioned profile endpoint. Responses use JSON and include typed profile data, API version metadata, and standard RateLimit headers. Unsupported methods return a structured error with a machine-readable code, message, and resolution hint.
