Yash Khalkar Authentication Documentation

The public Yash Khalkar developer resources do not require authentication. The OpenAPI document, developer portal, llms.txt file, and MCP server are intended for public discovery by developers and AI agents. Do not send passwords, API keys, session tokens, or private user information to these endpoints.

Public Access

Use standard HTTPS requests. The MCP server accepts JSON-RPC POST requests at /.well-known/mcp, supports the initialize, tools/list, and tools/call methods, and exposes the get_portfolio tool. GET returns a short endpoint description; OPTIONS reports supported methods.

Canonical Documentation

Start with the Yash Khalkar developer portal or inspect the Yash Khalkar OpenAPI specification. For agent-specific instructions and use cases, read llms.txt. Contact Yash Khalkar for collaboration questions.
