Vercel API Documentation

Read the Yash Khalkar Developer Portal for integration guidance, inspect the Yash Khalkar Portfolio OpenAPI specification for machine-readable API details, or read the Yash Khalkar authentication documentation before making requests. These resources are public and do not require an API key.

Vercel MCP Server

The Yash Khalkar MCP server uses Streamable HTTP and exposes the get_portfolio tool. MCP-compatible agents can initialize the endpoint, list its tools, and call the portfolio tool to retrieve canonical profile and project links.
