# Vehicle models

These CC0 GLB meshes are from Innerscene's original-model library. The library describes them as real-scale, unbranded visualization models. The portfolio uses them as visual stand-ins for the named vehicle classes; they are not manufacturer-accurate G 63, M5, Mini, Thar, GT3, F1, or motorcycle replicas.

- `suv.glb` — [Charcoal five-door crossover SUV](https://www.innerscene.com/tools/library/3d-parts/charcoal-five-door-crossover-suv-a1996830)
- `sedan.glb` — [Red four-door sedan](https://www.innerscene.com/tools/library/3d-parts/red-four-door-sedan-1d32e180)
- `hatchback.glb` — [Blue five-door compact hatchback](https://www.innerscene.com/tools/library/3d-parts/blue-five-door-compact-hatchback-5b95b2a0)
- `sport-motorcycle.glb` — [Sport motorcycle](https://www.innerscene.com/tools/library/3d-parts/sport-motorcycle-e21e8303)
- `adventure-motorcycle.glb` — [Adventure motorcycle](https://www.innerscene.com/tools/library/3d-parts/adventure-motorcycle-3de675e4)

Each source page identifies its model as CC0. The meshes are included locally so the game does not depend on a third-party asset host at runtime.
