# Human character models

Three textured, rigged CC0 people replace the game's procedural capsule figures. Each model contains seven named animation clips: idle standing, relaxed walk, brisk walk, jog, run, carrying walk, and sit/stand. The original models are larger (18–21 MB each); these web copies were optimized with glTF Transform and WebP texture compression, preserving the rigs and clips.

The sources are adapted from MakeHuman/MPFB CC0 body, rig, and skin assets and are released as CC0 on their Innerscene pages. This portfolio is not affiliated with Rockstar Games. These detailed, animated source models improve the people in the game, but are not Rockstar character scans or a claim of GTA V character fidelity.
